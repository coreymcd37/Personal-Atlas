# How to help

Thank you for looking at this. I put the globe up so other people could build on it. I would rather have a small honest fix than a huge rewrite I cannot follow.

## Before you start

1. Read the [README](README.md) and [docs/MAKE-IT-YOURS.md](docs/MAKE-IT-YOURS.md).
2. Look at the open issues. If one already describes your idea, comment there instead of opening a second one.
3. If nothing fits, open an issue first and tell me what you want to do. That way we do not both write the same thing.

## What I need most

- A way for someone who does not code to change the places.
- Footprints that draw themselves between the cities a person adds.
- Lived, been, and want to go as three different kinds of marks.
- A starter globe that is not my life story.
- A sharper earth when you zoom in.
- Names and footprints that stay a good size at every zoom.
- A globe that more people can actually use. Keyboard, contrast, and a way to report a barrier.

## How to send work back

1. Fork the repository.
2. Make a branch from `main`.
3. Keep the change small enough that I can read it.
4. Run `npm run typecheck`. If you can, run the app and click the thing you changed.
5. Open a pull request. In your own words, say what changed and which issue it closes.
6. I will write back on the pull request.

Do not send a pull request that only replaces my places with yours. Fork that and keep it. Send me the improvement that lets *anyone* do that.

## Reporting back

If you made a version for yourself, I still want to hear about it. Open an issue with the title "I made this mine" and tell me:

- what you used it for
- what was confusing
- what you wish the globe did next

That is how I find out if this is actually useful.

## Conduct

Be decent to people. The short version is in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
